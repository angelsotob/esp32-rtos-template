# 🏗 Architecture Overview

This project follows a layered architecture inspired by clean
architecture concepts for embedded systems.

Layers:

1.  Application Layer (`main/app/`)
    -   Contains FreeRTOS tasks
    -   Coordinates system behavior
    -   No business logic
2.  Domain Layer (`main/domain/`)
    -   Pure business logic
    -   No ESP-IDF or hardware dependencies
    -   Fully testable in isolation
3.  HAL Layer (`main/hal/`)
    -   Hardware abstraction layer
    -   Wraps ESP-IDF drivers
    -   Isolates hardware from business logic

Dependency direction:

Application → Domain → HAL

# ⚙️ How to Build

## 1️⃣ Clone the repository

git clone https://github.com/angelsotob/esp32-rtos-template.git  
cd esp32-rtos-template

## 2️⃣ Set up the ESP-IDF environment

Linux / macOS: . \$HOME/esp/esp-idf/export.sh

## 3️⃣ Configure the project

idf.py menuconfig

## 4️⃣ Build

idf.py build

## 5️⃣ Flash the device

Linux/macOS: idf.py -p /dev/ttyUSB0 flash

## 6️⃣ Serial monitor

idf.py monitor

# 📂 Folder Description

## 🔹 main/app/

Contains FreeRTOS tasks and system coordination logic.

Example: - app_main.c → Entry point - control_task.c → Periodic task
execution

## 🔹 main/domain/

Contains pure logic independent of hardware.

Example: - control.c → Decision logic (e.g., threshold comparison)

## 🔹 main/hal/

Contains hardware-specific implementations.

Example: - gpio_esp32.c → GPIO driver abstraction

## 🔹 build/

Automatically generated by ESP-IDF during compilation. Ignored via
.gitignore.

## 🔹 sdkconfig

Generated configuration file from menuconfig.

# 🧠 Example Execution Flow

1.  app_main() initializes hardware.
2.  FreeRTOS task is created.
3.  Task processes input values.
4.  Domain logic determines behavior.
5.  HAL updates GPIO state.

------------------------------------------------------------------------

# 🧩 Extending the Project

To add new functionality:

1.  Add logic in the Domain layer.
2.  Add hardware interaction in HAL if needed.
3.  Trigger behavior from Application layer tasks.

Keep responsibilities separated.
